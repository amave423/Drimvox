Git и GitHub в проекте

Сейчас в проекте одна кнопка «коммит», и непонятно, что и куда уходит. Три способа сделать это гибко. Во всех видно: какой репозиторий, какая ветка, какие файлы попадут в коммит и с каким сообщением.

A. Карточка в «Проекте» + окно сохранения. Настройки — в карточке справа. «Сохранить в git…» открывает окно: галочки у файлов, сообщение (агент предлагает), ветка, и сразу ли отправить на GitHub.
  • Просто и всё в одном месте.
  • Минус: истории коммитов нет, только последний.
