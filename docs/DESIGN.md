# Дизайн-система — «Корректура»

Выбран вариант **B3** из `design/variants-2.html` (2026-10-11). Этот файл — правила для всех
экранов. Токены в коде: `apps/web/src/styles/tokens.css`.

## Метафора

Работа агентов — это **рукопись на листе бумаги**, который лежит на каменном столе.
- Агент пишет **чернилами** (синий): добавленный код, пояснения, ход работы.
- Человек правит **красным карандашом**: замечания, возврат на доработку, удаление.
- **Поля листа** — место для заметок: пояснения агента и замечания владельца рядом со строкой.
- Зелёный — только для пройденных проверок. Им ничего не украшаем.

Каждый цвет несёт смысл. Если элемент не про агента, человека или проверку, он рисуется
нейтральными тонами.

## Логотип

Знак — лента, сложенная в букву D: стебель уходит в складку, складка темнее, у сгиба светлая грань. Градиент из
фиолетового в синий (`#8b6fe0` → `#3b7bd8`), без плитки. Единственный источник — `apps/web/src/assets/logo.svg`;
иконку приложения и картинки установщика из него рисует `node scripts/make-icon.mjs`. В интерфейсе знак рисует
`ui/Logo.tsx` из `--brand-from` / `--brand-to`. В верхней строке знак стоит рядом с «Drimvox», написанным шрифтом
интерфейса (Onest 600). Цвета знака от темы не зависят, но зависят от режима: в «Чате» фиолетовый → синий, в
«Проектах» весенний зелёный → хвойный (`#5ad17a` → `#127a5a`), смена плавная. Ими же окрашены знаки провайдеров,
серверов MCP и скиллов, а в тёмной теме — `--ink` и выбранное (`--choice`).

## Шрифты

- **Source Serif 4** — заголовки листов и экранов (600). Курсив (500) — рукописные замечания человека.
- **Onest** — весь интерфейс: 15px основной, 14px вторичный, 13px подписи.
- **IBM Plex Mono** — код, пути файлов, ветки, деньги и счётчики в таблицах.

Шрифты встроены в приложение (`@fontsource`), интернет для них не нужен.

## Форма

- Лист (`--sheet`) — прямой край без скругления, одна мягкая тень снизу. Только у листа есть тень.
- Карточки и поля ввода — радиус 10–12px, кнопки — капсулы (999px), мелкие строки списков — 8px.
- Главная кнопка — заливка `--fg` («Принять в main», «Начать работу»). Отказ — контур
  `--pencil` («Вернуть на доработку»). Остальные кнопки — `--sheet` с границей.
- Неактивная кнопка сохраняет контур, гаснет только текст. Выключенный тумблер — обведённая дорожка
  с приглушённым кружком, видна в обеих темах.
- Лист одной ширины на всех экранах; место под полосу прокрутки зарезервировано, лист не сдвигается.

## Элементы

- **Вкладки** (подчёркнутые) — разделы одной страницы: настройки, ключи, локальные модели, проект.
- **Переключатель-таблетка** — выбор значения: тема, язык, валюта, сервис поиска.
- **Чипы** — фильтры и подсказки: категории каталога, шаблоны проекта.
- **Настройка** — группа называется антиквой, сама настройка — подписью шрифтом интерфейса, под ней
  серой строкой что она делает, ниже элемент управления. Знак «?» в настройках не ставим.
- **Кнопка модели** — имя модели и рядом серым провайдер; id — только в подсказке и в списке.

## Компоновка

```
┌───────────────── верхняя строка (paper): Drimvox · проект / задача · расход ─────────────────┐
│ боковая (paper)     │                 стол (bg)                                             │
│ проекты, сессии,    │        ┌──────────── лист (sheet), до 900px ─────────────┐            │
│ проверки, файлы     │        │ заголовок serif                    │ поля 230px │            │
│                     │        │ содержимое: чат / план / diff      │ заметки    │            │
│                     │        └────────────────────────────────────┴────────────┘            │
├─────────────────────┴─────────── нижняя строка действий (paper) ──────────────────────────┤
```

## Тексты

- Предложения с заглавной буквы, без КАПСА, без точек в кнопках.
- Кнопка называет действие: «Принять в main», а не «ОК». Действие называется одинаково на всём пути.
- Ошибка говорит, что случилось и что делать. Пустой экран предлагает действие.
- Агент говорит о фактах: «Тесты 6 из 6», а не «Всё отлично работает!».

## Движение

Почти никакого. Анимация допустима только как ответ на действие: раскрытие, появление
новой строки хода работы, панель результата, выезжающая по ручке. Исключение — знак: при запуске окна (не в трей) он
рисуется по контуру и заливается, при смене режима рисуется в цвете нового режима; поверх окна, не перехватывая
нажатий. Уважаем `prefers-reduced-motion`.
