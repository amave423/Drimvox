# Спека: каталог серверов MCP и скиллов

## Зачем

Добавить сервер MCP можно было только командой, которую надо знать заранее. Пользователь попросил готовые карточки:
Playwright от Microsoft, Context7, GitHub, скиллы для документов и что-то для дизайна.

## Как выглядит

Настройки → «Инструменты» → «Каталог»: карточки с названием, видом (сервер MCP или скилл), строкой о том, что даёт,
переключателем и «Подробнее». «Подробнее» открывает окно: описание, команда или адрес, ссылка на проект; Escape или
крестик закрывают его. Ниже, как раньше, списки «Серверы MCP» и «Скиллы»: включённое из каталога видно там же.

## Что в каталоге

| Карточка | Что создаёт |
|---|---|
| Playwright | сервер `npx -y @playwright/mcp@latest` (официальный, Microsoft) |
| Context7 | сервер `npx -y @upstash/context7-mcp@latest` |
| GitHub | HTTP-сервер `https://api.githubcopilot.com/mcp/` с заголовком `Authorization: Bearer <токен>`; токен спрашивается в окне и хранится зашифрованным |
| Документы | общий скилл `documents`: Word, Excel, PowerPoint, PDF библиотеками, проверка файла после записи |
| Дизайн сайтов | общий скилл `web-design`: направление, шрифты, палитра, сетка, проверка на двух ширинах |

Тексты скиллов свои: скиллы Anthropic для документов распространяются по лицензии, которая не разрешает их встраивать.

## Поведение

- Включить: сервер создаётся (или включается снова, если уже есть), скилл записывается в общие скиллы.
- Выключить: сервер выключается (остаётся в списке с разрешениями), скилл удаляется.
- Своя карточка узнаёт уже добавленный сервер по команде или адресу (`@playwright/mcp`, `context7`,
  `githubcopilot.com/mcp`), скилл — по имени папки.
- Каталог живёт в интерфейсе (`apps/web/src/lib/catalog.ts`) и пользуется теми же API, что и ручное добавление.

## Тесты

- e2e: пять карточек; скилл «Документы» включается и выключается и виден в списке скиллов; GitHub при включении
  спрашивает токен в окне, Escape закрывает окно, ничего не добавляется.
