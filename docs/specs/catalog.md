# Спека: каталог серверов MCP и скиллов

## Зачем

Добавить сервер MCP можно было только командой, которую надо знать заранее. Пользователь попросил готовые карточки
с логотипами, подробным описанием и картинкой, больше серверов и настоящие готовые скиллы.

## Как выглядит

Настройки → «Инструменты» → «Каталог»: фильтр (Все, Браузер и веб, Код и работа агента, Дизайн, Документы) и
карточки: логотип, название, вид (сервер MCP или скилл) и автор, строка о том, что даёт, переключатель, «Подробнее».

«Подробнее» открывает окно: логотип, автор и лицензия, подробное описание, картинка «Как это выглядит» (маленький чат
Drimvox: просьба, действия, ответ), «Что умеет», команда или адрес сервера, откуда ставится скилл, ссылка на проект,
поле ключа, если он нужен. Escape или крестик закрывают окно.

Логотипы — из Simple Icons (CC0), одним цветом; у кого логотипа там нет, — простой значок Drimvox, без подделки чужого
бренда. Тексты карточек — `apps/web/src/locales/catalog.{ru,en}.ts`.

## Серверы MCP (13)

Playwright (Microsoft), Chrome DevTools (Google), Exa (без ключа), Firecrawl (ключ), Context7, GitHub (токен в
заголовке), Supabase (токен), Memory и Sequential Thinking (эталонные серверы MCP), shadcn/ui, 21st.dev Magic (ключ),
Figma (Framelink, токен), Notion (токен). Ключ передаётся в переменной окружения или заголовке, хранится зашифрованным.

## Скиллы (16)

- С GitHub, при включении: скиллы Anthropic под Apache-2.0 (frontend-design, canvas-design, theme-factory,
  algorithmic-art, webapp-testing, mcp-builder, skill-creator) и obra/superpowers под MIT (test-driven-development,
  systematic-debugging, brainstorming, writing-plans, verification-before-completion). Папка скилла берётся целиком,
  со скриптами и примерами (`POST /api/skills/install` с `source.kind = "github"`): дерево через API GitHub, файлы —
  с raw.githubusercontent.com; не больше 300 файлов и 20 МБ.
- Свои: docx, xlsx, pptx, pdf (`source.kind = "builtin"`, `packages/core/src/skills/builtin`). Скиллы Anthropic для
  документов не годятся: их лицензия запрещает хранить копии вне сервисов Anthropic.

## Поведение

- Включить: сервер создаётся (или включается снова), скилл ставится в общие скиллы.
- Выключить: сервер выключается (остаётся в списке с разрешениями), скилл удаляется.
- Карточка узнаёт уже добавленный сервер по команде или адресу, скилл — по имени в SKILL.md.

## Тесты
