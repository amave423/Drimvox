# Спека: другие компьютеры по SSH

## Зачем

Попросили удалённый доступ к другому компьютеру. Он уже был, но небезопасно (видели в чатах владельца): агент ходил
обычным `ssh` по ключу, а на VPS скачал `plink.exe` из интернета, вписал пароль `root` прямо в команду (`-pw …`) — пароль
остался в истории чата — и согласился с ключом сервера не глядя (`echo y`).

## Что видно

«Параметры → Настройки → Серверы SSH»: список серверов (название, `пользователь@адрес`, вход по ключу или паролю, «Спрашивать
каждую» / «Без вопросов», ключ сервера), «Проверить» (подключается и показывает `uname`), «Изменить», «Удалить»,
«+ Добавить сервер». Пароль уходит в ядро и обратно не возвращается; при изменении пустое поле оставляет прежний.

## Устройство

- `tools/ssh.ts` (`ssh2`, без внешних программ): серверы в `settings` (`ssh.servers`), пароль зашифрован. Вход по ключу —
  указанный файл, иначе ключ компьютера (`~/.ssh/id_ed25519`, `id_ecdsa`, `id_rsa`) или ssh-agent (Windows OpenSSH).
- Ключ сервера запоминается при первом подключении (`SHA256:…`); другой ключ потом — отказ с объяснением. Смена адреса
  или порта забывает ключ.
- Инструменты агента (чат с папкой и проект): `ssh_run` (сервер по названию, команда, таймаут до 30 минут), `ssh_upload`,
  `ssh_download` (SFTP, файлы этой стороны — внутри папки). Каждая команда спрашивает подтверждение, если сервер не
  «Без вопросов». Пароль вырезается из любого вывода. Инструменты есть, только когда сохранён хотя бы один сервер.
- `plink`, `putty`, `sshpass` через `run_command` спрашивают подтверждение (причина `ssh`).
- В сборке нет необязательных C++-модулей `ssh2` (`no-native.mjs`): он работает на криптографии самого Node.
- API: `GET/POST /api/ssh`, `PUT/DELETE /api/ssh/:id`, `POST /api/ssh/:id/check`.

## Тесты

- Ядро, настоящий SSH-сервер `ssh2`: команда по названию, пароль не в списке и не в выводе, подтверждение и отказ,
  «Без вопросов», ключ сервера запоминается, подменённый ключ — отказ; `plink`/`sshpass` спрашивают.
- e2e (упакованное ядро): сервер сохраняется в параметрах, «Проверить» подключается, пароля нет на странице.
