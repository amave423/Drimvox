# Спека: озвучка ответов на этом компьютере (Piper)

## Зачем

Голос Windows (Irina), которым читались ответы, звучал как робот. Пользователь попросил озвучку через Piper: естественные
голоса, бесплатно и без интернета.

## Как выглядит

- «Локальные модели» → «Аудио» → «Озвучка ответов»: голоса Piper — Ирина, Денис, Дмитрий, Руслан (русские) и Amy,
  Lessac (английские), голоса языка интерфейса первыми; размер, скачивание, пауза, удаление. Движок Piper скачивается
  вместе с первым голосом и удаляется отдельной кнопкой.
- У скачанного голоса — «Читать ответы этим голосом».
- Настройки → «Модели и деньги» → «Голос» → «Голос для чтения ответов»: «Голос Windows» или скачанные голоса.
- Кнопка «Слушать» у ответа читает выбранным голосом Piper; если голос не выбран или запись не пришла — голосом системы.

- Пока голос готовится, у кнопки крутится значок и написано «Готовлю озвучку…» (было: двадцать секунд тишины,
  как будто зависло). Ответ читается по частям: первая — до ~140 знаков, дальше по ~280, по границам предложений;
  следующая часть готовится, пока звучит текущая.

## Устройство

- Сборка Piper закреплена (`PIPER_TAG` 2023.11.14-2, последняя у rhasspy/piper; проект в архиве, сборки остаются):
  Windows x64 (zip), Linux x64 и arm64 (tar.gz). Символьные ссылки в tar (библиотеки onnxruntime) распаковываются
  копиями.
- Голоса — `rhasspy/piper-voices` на Hugging Face, medium (Lessac — high): модель `.onnx` тем же загрузчиком, что и
  остальные модели, и рядом её настройки `.onnx.json`.
- Настройка `speechVoice` (id голоса или null).
- `POST /voice/speak { text }`: текст без Markdown уходит в `piper --model голос --output_file wav` через stdin (UTF-8),
  ответ — `audio/wav`. Без выбранного голоса — 409 `no_speech_voice`.

## Тесты

- `packages/core/test/local-speech.test.ts`: голос скачивается вместе с движком, текст читается в WAV, движок и голос
  удаляются; без голоса чтение отказано.
