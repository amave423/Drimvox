# Провайдеры: что бесплатно

## Зачем

Попросили: из всего списка «Ключей и моделей» сразу видеть, у кого есть бесплатные модели, зайти на сайт и взять ключ;
отдельно — у кого бесплатно всё в пределах лимитов, у кого часть, у кого ничего. И чтобы у подключённых провайдеров
были верные цены, бесплатные модели были отмечены, а модели картинок находились.

## Как выглядит

- В «Подключить провайдера» карточки в группах: «Бесплатно с лимитами», «Есть бесплатные модели», «Только платные»,
  «Свой сервер» (LM Studio и любой адрес, совместимый с OpenAI). Под описанием карточки зелёным — что именно бесплатно
  («Все модели бесплатно: 30 запросов в минуту, до 1000 в день», «17 бесплатных моделей, без ключа»…).
- У подключённого провайдера рядом с числом моделей — «бесплатных: N» (нулевая цена или «бесплатно до лимита»).
- В выборе модели бесплатные отмечены и стоят первыми (как было); в разделе «Бесплатно» сами модели не помечены, и у
  провайдера, где бесплатны все, тоже. Без выбранной модели список открывается на первом провайдере по ключу, затем по
  подписке, а модели этого компьютера — последними (замечено: с подключённой Ollama он открывался на ней).
- **Рассуждения в истории.** Провайдер, отвечающий, что не принимает `reasoning_content` в прошлых ответах
  (замечено: цепочка перешла с DeepSeek на другого посреди проекта, и каждый запрос падал), получает тот же запрос
  без них (`withoutHistoryReasoning`).
- **Подписки по ключу** (попросили: подписок было всего три CLI). На вкладке «По подписке», рядом с CLI, — подписки
  вендоров для кода с их собственным ключом и адресом, совместимым с OpenAI (`plan: true`): «GLM Coding Plan (Z Code)»
  (`https://api.z.ai/api/coding/paas/v4`), «Kimi Code» (`https://api.kimi.com/coding/v1`), «Alibaba Coding Plan (Qwen)»
  (`https://coding-intl.dashscope.aliyuncs.com/v1`). Подключённые сразу с фиксированной оплатой (`flat`): токены
  считаются, деньги нет. Их модели работают в агенте Drimvox со всеми его инструментами, а не в чужой программе.
  Через CLI их не подключаем: у Z Code фоновый режим на подписке не работает (открытые баги Z.ai), Kimi Code и Qwen Code
  на подписке ходят на эти же адреса.

## Кто бесплатный (проверено 2026-11 по страницам провайдеров, их каталогам и живым запросам)

- Всё бесплатно с лимитами (`free: "all"`, модели помечены `freeTier`): Groq, Cerebras, Mistral (тариф Experiment),
  NVIDIA NIM, Cohere (пробный ключ), Cloudflare Workers AI (10 000 «нейронов» в день), OVHcloud (без ключа, 2 запроса в
  минуту на модель).
- Часть бесплатна (`free: "some"`): Gemini (Flash, Flash-Lite, Gemma), OpenRouter (`:free`), LLM7 (модели Turbo — без
  ключа; проверено живым запросом, Pro просят ключ и деньги), Kilo Code Gateway (17 бесплатных без ключа — проверено),
  Vercel (модели «Free» и $5 в месяц), Hugging Face (небольшой кредит в месяц), Pollinations.
- Добавлены во второй круг (попросили: и неофициальных, у кого есть бесплатные модели; найдены по подборкам SoftHive, Хабра и
  airassvet, у каждого проверен адрес): Ollama Cloud и Gonka (всё бесплатно с лимитом), Zhipu (open.bigmodel.cn, модели
  Flash), OrcaRouter (7 моделей «-free» в открытом каталоге), TeamoRouter, NaraRouter (бесплатно после привязки Telegram),
  Agnes AI; у OpenCode Zen — 7 моделей «-free» (цены в его каталоге — `cost` за миллион, как у models.dev).
- Не добавлены: FreeRouter (сервер не отвечает), Glhf.chat (ошибка 526), Cline (пускает только свою программу), Token
  Harbor (бесплатно только 7 дней), ModelScope (не открывается отсюда; нужна китайская верификация), Aion Labs (в
  каталоге только платные цены), GitHub Models (вместо списка моделей отвечает «OK»), SiliconFlow (нужна китайская
  верификация), международный Z.AI бесплатных моделей не даёт (бесплатные Flash — у китайского Zhipu).

## Каталоги (`providers/catalog.ts`, `media/catalog.ts`)

- Цены: `prompt`/`completion` за токен, или `input`/`output` (Vercel, LLM7); у LLM7 — за миллион токенов
  (`unit: "1M tokens"`); у Hugging Face — у каждого провайдера модели, берётся самый дешёвый живой, `is_free` — бесплатно
  (видели: у Vercel 260, у Hugging Face 62 цены «неизвестна»).
- Только модели для чата: каталоги с типом модели (`type` у Vercel, `model_type` у LLM7) — только `language`/`chat`;
  выход модели — также из `modalities.output` (Vercel).
- Картинки у каталогов с типом модели: `type: "image"` — через `/images/generations` (цена за картинку из `image` или
  `price` с `unit: "image"`), модели для чата с картинкой на выходе — через чат. Видео там пока не предлагается: общего API
  нет. Видели: Vercel — 45 моделей картинок, LLM7 — 7 (раньше «нет»).
- Perplexity отвечает в корне, а список моделей — в `/v1/models`; Cloudflare — в `/ai/models/search?task=Text
  Generation`, в адресе — номер аккаунта (форма подсказывает, где его взять).
- Не оценены: «-highspeed» у Kimi и MiniMax (их нет в каталоге OpenRouter), часть моделей Cohere у Hugging Face.

## Кто учится на запросах

Бесплатное использование OpenRouter (у большинства хостов моделей «free»), NVIDIA (пробный доступ) и Google AI Studio
(бесплатный уровень) по их условиям может идти на обучение моделей. Под карточкой таких провайдеров при подключении —
серая строка «Бесплатные модели могут учиться на ваших запросах…» (`trainsOnFree` в пресете; совет из видео про агентов:
не отправлять бесплатным моделям то, что не показали бы постороннему).

## Что известно о моделях

- **Бесплатные по меткам списка** (`catalog.ts`): кроме цен в стиле OpenRouter — `is_free`/`isFree`/`free`, `tags`
  строкой или списком со словом free, цены за миллион под своими именами (`price_in_per_m`), имя `free/…` или `…:free`.
  Состояние из списка: `status` degraded/overloaded → «перегружена», down/offline/unavailable или `available: false` →
  «не отвечает». Попросили: у BlazeAPI бесплатные модели показывались платными.
- **Ответы учат** (`learnFromAnswer`): ошибки и успехи и чата, и агента проекта запоминаются для всех провайдеров в
  интернете (не для консольных агентов и моделей на компьютере). Новые коды: `no_tools` — модель не умеет инструменты,
  Drimvox запоминает, и следующие запросы идут к ней без них; `too_large` — запрос больше окна модели или лимита её
  бесплатного тарифа в минуту (Groq: «Request too large … TPM»), модель на время считается неотвечающей. Пробный запрос
  делается и к моделям, бесплатным по тарифу (LLM7 Turbo), а не только с нулевой ценой.

## Один провайдер модели у посредников (2026-11-10)

У RouterAI и OpenRouter одну модель обслуживают многие провайдеры: у DeepSeek 1017 на RouterAI их 48, вход от 0,71
до 269 ₽ за миллион, у каждого свой кэш. Без нашего выбора RouterAI раскидывал шаги одного разговора по разным
провайдерам: цена шага скакала в разы, кэш пропадал при каждой смене, пробный запрос ушёл провайдеру за 35,5 ₽ вместо
11,95 ₽ с карточки модели. Теперь (`providers/routing.ts`) Drimvox берёт список провайдеров модели
(`GET /models/{модель}/endpoints`, без ключа, раз в 6 часов) и шлёт `provider: { order: [самый дешёвый] }`, запасные
провайдеры разрешены. Самый дешёвый — по работе агента: 15 % входа новые, 81 % из кэша, 4 % ответ (замер на сайте
погоды); без цены кэша весь вход считается новым. Страна не важна (попросили). Пропускаются отключённые (`status` < 0),
без инструментов и варианты «/flex», «/priority» (другая очередь). Запрос со своим `provider` или `@` в имени модели не
трогается. В замере шага (`DRIMVOX_TRACE_STEPS`) — сырой `usage` провайдера с его `cost`.
