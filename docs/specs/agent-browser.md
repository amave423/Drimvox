# Браузер агента

Попросили: браузер Playwright не должен открываться отдельным окном; нужно как у Claude — кнопка справа сверху и
панель внутри Drimvox, где видно, что делает агент, и можно самому пройти проверку «я не робот».

## Что видно

- Кнопка «Браузер» справа в верхней строке; зелёная точка — браузер агента запущен. Нажатие открывает панель справа
  поверх окна: «Назад», «Обновить», адрес (Enter открывает), закрыть.
- В панели — текущая вкладка браузера, обновляется вживую. Нажатия, прокрутка, ввод с клавиатуры и вставка (Ctrl+V)
  уходят в страницу. Под адресом — заголовок страницы.
- Браузер запускается сам, когда агенту понадобился Playwright, или кнопкой «Открыть браузер» в панели.

## Устройство

- `packages/core/src/browser/agent-browser.ts` — Chrome или Edge этого компьютера (иначе Chromium из кэша
  Playwright) без окна (`--headless=new`, обычный user-agent без «Headless»), со своим профилем в папке данных
  (`agent-browser`): входы на сайты и пройденные проверки сохраняются. Управление — протокол DevTools: вкладки по
  событиям `Target`, картинка — `Page.startScreencast` только пока панель открыта, ввод — `Input.*`, заголовок и адрес
  читаются со страницы при загрузке и раз в секунду.
- Сервер Playwright (`@playwright/mcp`) подключается к этому браузеру: Drimvox убирает из его команды `--headless`,
  `--browser`, `--isolated` и добавляет `--cdp-endpoint` и `--output-dir` в папку данных. Нет Chrome/Edge — сервер
  работает со своим браузером, как раньше.
- API: `GET /api/browser` — состояние, `GET /api/browser/stream` — поток событий `frame` и `state`,
  `POST /api/browser/open|input|back|reload`. Ввод в окне идёт по очереди, по порядку действий.

## Тесты

- Ядро: команда Playwright переписывается; настоящий браузер показывает вкладку картинками, принимает клик и ввод,
  сообщает адрес и заголовок (пропускается, если на компьютере нет Chrome/Edge).
- e2e: кнопка «Браузер» открывает панель, адрес открывает страницу, клик и ввод в картинке меняют страницу, на кнопке
  появляется точка.
