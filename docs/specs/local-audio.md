# Спека: распознавание речи на этом компьютере

## Зачем

Пользователь попросил движок для локальных аудиомоделей и вкладку «Аудио»: диктовать сообщения бесплатно и без
интернета, а в выборе модели для голоса видеть только модели, которые слышат звук.

## Как выглядит

- «Локальные модели» → «Аудио»: Whisper Base (быстрая), Whisper Small (оптимальная), Whisper Large v3 Turbo (точная)
  с размером, скачиванием, паузой и удалением. Движок whisper.cpp скачивается вместе с первой моделью.
- У скачанной модели — «Сделать моделью для голоса».
- Настройки → «Модели и деньги» → «Голос»: в выборе модели только провайдеры, у которых есть модели со звуком
  (`ModelInfo.audio`: из каталога, `input_modalities` с `audio`), и только эти модели; без вкладок картинок и видео.

## Устройство

- Сборка whisper.cpp закреплена (`WHISPER_TAG`): процессорная для Windows x64 и Linux x64 (zip и tar.gz).
- Модели — `ggerganov/whisper.cpp` на Hugging Face, тем же загрузчиком, что и картинки (через прокси при надобности).
- Провайдер `whispercpp` (`drimvox://whisper`) появляется после первой модели; его модели — скачанные, `audio: true`,
  бесплатные. В «Ключах и моделях» и в выборе модели для чата его нет.
- Диктовка: окно пишет WAV 16 кГц моно; `POST /voice/transcribe` для `whispercpp` запускает
  `whisper-cli -m модель -f файл -l auto -nt -np` и возвращает текст.
- Облачная модель для диктовки получает запись с выключенным мышлением (видели: бесплатная «reasoning»-модель каждый раз
  отвечала пустым текстом, и окно писало «не удалось распознать»), до трёх попыток. Пустой ответ — «Модель не услышала
  речи» (`nothing_heard`, 422); ошибка провайдера показывается рядом с кнопкой его словами.
